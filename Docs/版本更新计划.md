# 版本更新计划

> 依据《游戏基础设定》版本管理部分：
> - 大版本（v0 / V1 / V2 …）才上传 GitHub；
> - 小版本（v0.1 / v1.1 …）仅本地提交，不推送远端。

## 版本规则

- 格式：`v<大>.<小>`（如 v0.0、v0.1、V1.0、V1.1）。
- 大版本语义：项目阶段里程碑（骨架完成 / 水体可运行 / 优化交付）。
- 提交规范：`<type>: <描述>（<上下文>）`，type 同 git 惯例（feat/fix/docs/art/refactor/chore…）。
