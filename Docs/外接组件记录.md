## MCP 服务器连接说明（重要）

- **MCP 服务器（stdio 模式）**：
  `node "C:\Users\18689\.vscode\extensions\gamedevtoi.gdt-unity-mcp-server-0.1.13\dist\unity-mcp.js"`
  （默认连接编辑器桥端口 6400）
- **Unity 端桥**：项目打开后 `Assets/Editor/UnityBridge/UnityBridgeServer.cs` 的
  `[InitializeOnLoad]` 静态构造自动启动，监听 `ws://127.0.0.1:6400`；
  主线程 `EditorApplication.update` 队列执行命令。
- **协议**：WebSocket 文本帧 JSON：`{"id":"...","action":"<action>","params":{...}}`，
  支持动作：ping / createScene / createGameObject / setProperty / createPrefab /
  createScript / addComponent / setComponentProperty / instantiatePrefab /
  getSceneHierarchy / findGameObjects / listAssets / setMaterial / saveScene /
  refreshAssets / openScene / deleteGameObject / runMenuItem / captureScreenshot 等。
- 历史问题记录（MCP测试 项目排过）：AssetImportWorker 子进程抢先占用 6400 →
  UnityBridge 已做 IsImportWorker 判断跳过 + 失败延迟重试。

## REA 逆向工具（2026-10-16 固化接入）

- **是什么**：Reverse Engineering Assistant v4.0.0 —— GitHub 开源（mytechnotalent/rea）、纯 Rust 的自主二进制逆向框架。
  CLI 或 MCP 服务器两用；MCP 暴露 12 个工具：open_binary / binary_session / list_functions /
  decompile_function / find_xrefs / search_strings / inspect_dotnet / inspect_go / inspect_android /
  analyze_firmware / analyze_javascript / generate_dossier。
- **固化路径**：`E:\Git hub close\REA\bin\rea.exe`（2026-10-16 从 `rea-src\target\release` 拷出，防 `cargo clean` 失效）；
  项目内包装脚本 `Tools/rea.ps1`（例：`powershell -ExecutionPolicy Bypass -File Tools/rea.ps1 info <file>`）。
- **MCP 接线**：OpenCode 全局配置 `C:\Users\18689\.config\opencode\config.json` 与 Claude Code（REA 目录项目级）
  均已指向固化路径；**重启 OpenCode 后** AI 会话即可直接调用 rea 的 12 个工具。
- **适用边界（重要）**：只做**文件/二进制层取证**（PE/ELF/Mach-O、.NET CIL、固件、APK、ASAR 等）。
  视频文件、AssetBundle、打包后的 GPU Shader 字节码**不适用**——视频对照走「抽帧 + 像素/参数比对」流程
  （见《03_可复现流程》与 Tools/compare_reference.py、Tools/sample_png.ps1 等；本机 Python 3.12 已装 cv2 可用）。
- **使用说明**：`E:\Git hub close\REA\REA-使用说明.md`。
