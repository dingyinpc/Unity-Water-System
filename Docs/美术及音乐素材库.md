## 使用规范（总则）

1. 来源必须可追溯：记录购买方、许可证类型、链接。
2. 只使用授权允许商用/学习分发的素材；免费素材需确认许可证（CC0 / 免费商用 / 仅个人）。
3. 不提交来源不明素材到 git；付费素材只记录清单与链接，不 clone 进仓库。
4. 每个素材条目登记：用途、保存路径、来源、许可证、备注。

## 荷花素材包的定位（候选清单）

视频作者说明"荷花用的是 Unity 商店的素材包"，未给出确切名称。**账号状态：已登录**
（Unity 账号 d13077436136@gmail.com，token=True，2026-09-16 检测）。

### 判别标准（对照视频画面）
1. 荷花形态：花瓣层数、粉色→白色渐变、莲蓬细节；
2. 渲染风格：与视频一致的写实/半写实风格（视频为 HDR 光影、折射水体）；
3. 是否带荷塘组合（水草、浮萍）——用于场景摆景更省力；
4. 许可证：个人版/专业版可商用均可（本项目为学习用，仍按规范登记）。

### 候选（按常见度排序，均为商店搜索候选，需在商店页面比对后确认）
| 候选 | 类型 | 商店搜索词 |
| ---- | ---- | ---------- |
| Lotus Plant / 荷花单体包 | 写实莲花+莲蓬+荷叶 | `lotus` |
| Pond Plants & Lotus（荷塘植被组合） | 荷塘生态组合包 | `lotus pond` / `pond plants` |
| 东方园林/水景场景包（含荷花） | 场景摆景 | `oriental garden` / `lotus garden` |
| 免费荷花（Free Lotus） | 免费福利款，质量参差 | `lotus free` |

商店直达搜索：
- 网页：https://assetstore.unity.com/?q=lotus
- 编辑器内：Window → Asset Store（登录态已具备）→ 搜索 `lotus` / `荷花`

### 操作流程（确认包名后）
1. 商店页面打开候选 → 点 **Add to My Assets**；
2. 编辑器内 **Window → Package Manager → My Assets** 找到该包 → **Download**；
3. 告知我包名/导入路径 → 我负责：导入整理到 `Assets/Art/StylePacks/正式素材/Lotus/`、
   制作成可复用预制体 `Assets/Prefabs/Lotus_*.prefab`、按莲塘布局摆进 `Main.unity` 并登记版权。
