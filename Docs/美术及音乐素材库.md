> 依据《游戏基础设定》文档记录部分：记录素材来源与使用规范，**版权问题尤为重要**。
> 目录规范：正式素材与备用素材按风格分目录存放：
> `Assets/Art/StylePacks/正式素材/` 与 `Assets/Art/StylePacks/备用素材/`

## 使用规范（总则）

1. 来源必须可追溯：记录购买方、许可证类型、链接。
2. 只使用授权允许商用/学习分发的素材；免费素材需确认许可证（CC0 / 免费商用 / 仅个人）。
3. 不提交来源不明素材到 git；付费素材只记录清单与链接，不 clone 进仓库。
4. 每个素材条目登记：用途、保存路径、来源、许可证、备注。

## 荷花素材定位（最终采用：免费平替）

**结论（2026-09-17）**：付费包「Stylized Poly Nature - 3D 场景+昼夜循环+动态云影」（作者 Nicrom，中国商店 ID 20002216，
¥315→¥220.5，内含睡莲花×4/睡莲叶×7/香蒲等）与用户口述的「Unity_Grasslands-Stylized Nature」疑似同款——
**但用户选择不购买，改找免费平替**。最终采用 poly.pizza 免费 CC BY 3.0 模型（无需登录、直链下载、许可证干净）：

### 已导入素材明细
| 文件 | 内容 | 大小 | 来源 | 许可证 |
| ---- | ---- | ---- | ---- | ---- |
| `WaterLilies_GooglePoly.glb` | 睡莲/荷叶簇（多株，含花朵） | 1813 KB | https://poly.pizza/m/birD7XV2A44 （Poly by Google） | CC BY 3.0（署名：Poly by Google） |
| `LotusFlower_SeanTarrant.glb` | 单株粉莲（"One pink lotus flower"） | 70 KB | https://poly.pizza/m/6rLIFNbNTRG （Sean Tarrant） | CC BY 3.0（署名：Sean Tarrant） |

- 导入方式：UPM 包 **com.unity.cloud.gltfast 6.4.0**（GLB→Prefab 原生导入，见《外接组件记录》）；
  在编辑器内存档即作为预制体使用，场景实例直接引用 `.glb` 资源。
- 摆景（Main.unity，40m 圆池，v0.6.2 对标视频重摆）：荷叶/粉莲小散簇 ×5【(4.5,-2.5)/( -5.5,1.0)/(2.0,5.0)/(-2.2,6.5) 荷叶簇 + (6.0,3.0) 粉莲】，均贴水 y≈0.03、缩放 0.55~0.75，远近错落仿视频。
- **版权义务**：CC BY 3.0 要求署名——本项目文档与演示中注明出处（poly.pizza 模型名+作者）即可，已满足。

### 环池外景树木（对标视频，v0.6.2 引入）

- 来源：poly.pizza 模型 **"Trees"**（作者 Quaternius，https://poly.pizza/m/etFGNvsiFv），**CC0 公有领域**，3.3MB；
- 导入：`Assets/Art/StylePacks/正式素材/Trees/Trees_Quaternius.glb`（经 com.unity.cloud.gltfast 转预制体）；
- 用法：菜单 13「对标视频外景绿化」生成 34 株双环（主环 22 株 20.8~25m + 内环 12 株 22.2~23.4m 插空，高 1.1~2.8 倍缩放），地面换草绿 `GrassGround.mat`（湖底 PondFloor 保持沙色以保折射湖底质感）。
