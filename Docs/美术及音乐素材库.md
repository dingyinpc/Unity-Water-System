# 美术及音乐素材库

> 依据《游戏基础设定》文档记录部分：记录素材来源与使用规范，**版权问题尤为重要**。
> 目录规范：正式素材与备用素材按风格分目录存放：
> `Assets/Art/StylePacks/正式素材/` 与 `Assets/Art/StylePacks/备用素材/`

## 使用规范（总则）

1. 来源必须可追溯：记录购买方、许可证类型、链接。
2. 只使用授权允许商用/学习分发的素材；免费素材需确认许可证（CC0 / 免费商用 / 仅个人）。
3. 不提交来源不明素材到 git；付费素材只记录清单与链接，不 clone 进仓库。
4. 每个素材条目登记：用途、保存路径、来源、许可证、备注。
