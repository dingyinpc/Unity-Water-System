# 美术及音乐素材库

> 依据《游戏基础设定》文档记录部分：记录素材来源与使用规范，**版权问题尤为重要**。
> 目录规范：正式素材与备用素材按风格分目录存放：
> `Assets/Art/StylePacks/正式素材/` 与 `Assets/Art/StylePacks/备用素材/`

## 使用规范（总则）

1. 来源必须可追溯：记录购买方、许可证类型、链接。
2. 只使用授权允许商用/学习分发的素材；免费素材需确认许可证（CC0 / 免费商用 / 仅个人）。
3. 不提交来源不明素材到 git；付费素材只记录清单与链接，不 clone 进仓库。
4. 每个素材条目登记：用途、保存路径、来源、许可证、备注。

## 荷花素材包的定位（候选清单）

视频作者说明"荷花用的是 Unity 商店的素材包"，未给出确切名称。候选（按常见度排序）：

1. **Lotus Park**（莲花/荷塘相关场景包）
2. **Lotus Plant Pack**（荷属植物单体包，含低模/高模变体）
3. **Fantasy Water & Lotus** / 东方风格公园植物类包

商店搜索链接：https://assetstore.unity.com/?q=lotus
**决策流程**：打开上述链接或编辑器内 Window → Asset Store，搜索 "lotus"，比对视频画面中的荷花形态
→ 确认包名 → 点击 Add to My Assets → 编辑器内导入。
⚠️ 该步骤需要您的 Unity 账号登录态，届时需您配合操作（或告知我账号侧已完成）。
