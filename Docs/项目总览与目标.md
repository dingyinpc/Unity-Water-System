# 项目总览与目标确认（v0.1）

> 本文档是《Unity3D 风景的项目立项》的目标确认书，依据三份输入文档（游戏基础设定 / 学习路径以及知识库的搭建 / 最终目标的标准）整理。

## 一、立项背景

- 立项人：2D Unity 开发较精通的学生，3D 方向新手（基础扎实）。
- 起因：看到抖音作者「雨鱼鱼雨雨雨」的 Unity 水体 Shader 视频，希望学习其技术栈。

> 视频链接：https://v.douyin.com/xkgQ9nxCcOA/ （抖音视频 ID：7682599302389277618）
> 视频简介：unity 水体 shader，用到自适应曲面细分、格斯特纳波、屏幕空间折射、折射深度保护、
> 动态水体交互、RNW 法线混合、程序化 ripple、格斯特纳波驱动的浪尖效果。
> 作者自述：荷花来自 Unity 商店素材包；可参考《地平线：零之曙光》的水体思路。

## 二、目标（DoD，Definition of Done）

1. 【骨架】按《游戏基础设定》搭建工程：Assets 分类（美术/音乐/预制体/动画/脚本/场景）、
   三层脚本架构（表现层/逻辑层/数据层）、文本文档体系、git + GitHub 版本管理。
2. 【MCP】连接 Unity MCP 服务器（gamedevtoi.gdt-unity-mcp-server v0.1.13 + UnityBridge 6400 桥），
   主要内容通过 MCP 处理。
3. 【场景】新建场景。
4. 【水体】复刻视频水体 Shader 的 8 项效果：
   自适应曲面细分 / 格斯特纳波 / 屏幕空间折射 / 折射深度保护 / 动态水体交互 /
   RNW 法线混合 / 程序化 ripple / 格斯特纳波驱动的浪尖效果。
5. 【素材】从 Unity 商店找到并下载视频同款荷花素材包。
6. 【文档】产出完整、可复现的学习路径与学习过程（MD 文档），并持续随进度更新。

## 五、范围边界（明确不做 / 延后）

- 不追求与视频 1:1 像素级复刻，以"效果可复现 + 技术要点完整"为标准；
- FFT 海浪（Tessendorf）暂不引入（格斯特纳波已覆盖项目需求）；
- 性能优化仅做常规（合批、RT 分辨率、细分上限），不做多平台发布调优；
- 荷花素材包下载依赖 Unity 账号与商店操作，需要立项人提供账号侧操作（见素材库文档）。
