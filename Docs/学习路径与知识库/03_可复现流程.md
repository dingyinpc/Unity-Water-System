## 3. 建场景 + URP 资产（阶段2）

  指定 Global Settings 为 URP，并在 URP Asset 开启 **Opaque Texture** 与 **Depth Texture**（折射必需）。

## 7. FAQ / 踩坑记录（持续回填）

| 坑 | 现象 | 解法 |
| -- | ---- | ---- |
| Start-Process 拆参数 | 项目路径含空格时编辑器启动失败退出 | `-ArgumentList "-projectPath \`"路径\`""` 手动加引号 |
| PowerShell 执行策略 | 桥客户端脚本被拒 | `Set-ExecutionPolicy -Scope Process Bypass -Force` 或 `-ExecutionPolicy Bypass -File` |
| createScene Additive 模式 | "Cannot create a new scene additively with an untitled scene unsaved" | 改进桥：改用 `NewSceneMode.Single` |
| addComponent 找不到带命名空间脚本 | "Component type 'X' not recognised" | 改进桥 ResolveComponentType：按类名（不含命名空间）模糊匹配 + 反射异常保护 |
| HLSL float2 用了 .z | `invalid subscript 'z'` | 二维方向量只有 .x/.y，换成 .y |
| HLSL 噪声 du 声明成 float | `invalid subscript 'y'` | `float2 du = 6.0 * f * (1.0 - f);` |
| HLSL 函数内嵌函数定义 | `syntax error: unexpected token '('` | 提到文件作用域 |
| Shader 编译错误卡编辑器 | 编辑器程序集编译失败时桥仍在跑旧代码 | 看 Editor.log 的 `error CS`；修完 refreshAssets 重编译 |
| 场景视角被切走 | 截图一片深绿（是湖底地面） | 设置脚本加"对齐水景视角"菜单项固定 SceneView 取景 |
| SceneView 截图不随取景变化 | Play 模式下 LookAt 后 cam.Render() 仍拍旧画面 | 截图前把 `sv.pivot/rotation/size` 显式应用到相机（桥已修） |
| Play 中重导入 Shader 后画面洋红 | 变体被卸载，材质显示错误色 | 退出再重新进入 Play（避免在 Play 中改 Shader/材质） |
| 俯视角水面一片橄榄绿 | 折射层混合用了平铺系数，俯视时湖底色主导 | 折射混合改为按水深加权（浅水看底、深水看深色水） |
| 水面试图太亮/太暗 | 湖底沙色与折射权重失衡 | `_BaseColor` 用中等棕褐沙 + 折射权重 0.58 |
