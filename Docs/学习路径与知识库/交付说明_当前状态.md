## 三、这一阶段改了什么（R90–R107）

### 1. 去"纸板感"

| 原来 | 现在 | 怎么发现的 |
| --- | --- | --- |
| 云是**灰色圆角方块**，边缘是笔直的线 | **团状积云**，边缘碎化 | 加了一个"只看云遮罩"的调试模式，一眼看出轮廓就是噪声格子 |
| 礁石是**纯白/纯黑的多边形**（在两种状态间反复横跳） | 深灰礁石，有层理、斑点、明暗面 | 逐屏拾取定位到具体物体，再换"程序化岩石"材质 |
| 沙滩像**灯芯绒布** | 细沙 + 大尺度色斑 | 沙粒噪点强度 ±42% 太高，降到 ±15% |

### 2. 去"玻璃/锡纸感"（水面）

- 水面高光强度被设成了 **2 倍**、锐度 200 —— 像揉皱的锡纸 → 降到 0.6 / 90
- 水面有一层**多边形网格纹** → 隔离实验证明来自"细节法线"，换成另一种噪声后消失大半

### 3. 修"黑背景 / 黑块"

- **Pool** 的背景是 Unity 自带天空盒的"下半球"（深褐色）→ 换成浅雾色
- **FFT / Islet** 地平线有一条深灰粗带 → 同一个原因（天空"地平线以下颜色"太深），已修 **三次**
- **Main** 中间那块纯黑巨石 → 换成带"天光填充"的材质，现在有明暗面

### 4. 修"暗"和"过曝"

- **Pond** 的后处理**从来没开过**（相机上一个开关是关的），而它的曝光又被写成 +2.8（一开就白屏，所以当年关掉）
  → 开后处理 + 曝光重标定 = **亮度 54 → 72**，"黄昏黑水潭"变"正午林间"
- **Pool** 池沿 6.2% 面积过曝 → 3.9%

### 5. 顺带修好的工具问题

- 截图工具原来**没开抗锯齿**，我看到的截图比实际游戏画面更毛糙（已修）
- **一次事故**：Pond 开后处理后，Bloom 把一个高光点糊成**覆盖 60% 画面的白洞**；
  而我当时"改完立刻验"量到的是**旧帧**，所以没发现，直到全场景回归才抓到。
  教训已写进规范：**改完立刻验证的结论不算数，必须确认真的换了一张图**。

## 六、关于"像不像参考"

参考视频是**俯视浅水**（水面占满画面），我们的 Ocean 是**沙滩平视全景**。
两者构图不同，所以"相似度"这类数字意义有限。

真正能对齐的是**观感要素**：蓝天白云 ✓、青绿海水 ✓、白沙滩 ✓、礁石有质感 ✓、云是团状 ✓、
水面有波纹但不油腻 ✓。

剩下的是**模型精度**层面的差距（低多边形 vs 真实资产），这不是调参数能解决的。
