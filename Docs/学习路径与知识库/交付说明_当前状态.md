## 三、这一大段（R108–R145，约 30 轮）改了什么

### 1. 水

| 问题 | 原因 | 结果 |
| --- | --- | --- |
| Ocean 水面"蒙了层脏纱窗" | 泡沫历史场是**分格数据**，中远景碎成马赛克 | 高频碎点 **−57%** |
| Islet 泻湖一层"白芝麻" | 两层**同方向**噪声叠出摩尔纹，被锐利高光显影 | 纯白像素 **−89%** |
| Islet 泻湖"一片均匀" | 只有按水深的单一渐变，湖底又平 | 加**水底斑块**（亮沙洲/深色海草）+ 波纹错向；色调范围 38→**42**（进参考区间） |
| FFT 海面大块白色方块 | L0 贴图 0.98 米一格 + 针尖状反光把插值折痕放大 | 耀斑放宽 + 泡沫去掉逐格常数 + 距离渐变柔化 → **方块消失** |
| FFT 帧耗翻倍 | 每步都重算"云有多高"（100 次/像素） | 改成每条射线算 2 次 → **23.6 → 14.2ms** |

### 2. 天空与云

- **云从"软团块"变"花椰菜"**：换成细胞状噪声（Worley），只扭坐标不改噪声强度 ⇒ 云量不变、边缘长球，细节 **+19%**；
- **云有体积了**：加"多次散射"近似（光在云里反复弹），天空对比 **+6%**；
- **天空发白**：天顶压深 60%，画面从"灰白"变"真正的蓝天"；
- **地平线一排小黑点**：查清是云的掠射椒盐（不是步进/阴影/密度），最终用**只作用于天空的轻微模糊**后处理解决（盐椒点 −18%，代价 0.4ms）；
- ⚠ 一次失败的尝试：AI 生成"俯视积云图"接管云形状，四种接法全部失败（体渲染的柱状模型吃不了平面图），已记档。

### 3. 地面与植被

| 问题 | 原因 | 结果 |
| --- | --- | --- |
| 棕榈叶像塑料 | 贴图饱和 81 **再乘**高饱和绿色底 ⇒ 双重饱和 | 贴图去色 + 低饱和底 → **深绿有层次** |
| 礁石"绿土豆" | 苔藓权重取顶点色，而顶点色恒为 1 ⇒ 整块全绿 | 苔覆盖封顶 0.15 + 岩色提亮 + 玄武岩贴图 → **近黑 13.2%→5.4%** |
| 远处植被一条黑线 | 灌木反照率只有 **4%**，背光归零 | 提到 5 倍 → 深绿灌木 |
| 崖体背光死黑 | 填充光不足 | +40% → 全画面 <40 像素 **−44%** |
| 巨岩"一摞薄饼" | 层理是三个**只随高度**的正弦 ⇒ 水平直线 | 取样高度按噪声揉动 → 波浪状岩层 |
| Ocean 沙滩"沙漠黄" | 暖色底 × 暖阳光 × 暖贴图三重叠加 | 底色调中性 → 沙色与参考**几乎逐位相同** |
| 沙滩斜向网格纹 | 沙贴图**带大块明暗**，每 1.8 米重复 | 高通滤波只留颗粒 → 网格消失 |

### 4. 一个反复出现的"影子问题"

这一大段里，**同一个病出现了四次**：棕榈叶、礁石、沙滩、灌木——
都是"**底色本身已经很饱和/很暗，再乘一层同类颜色**"，结果溢出。
解决办法统一为：**贴图管明暗，底色管色相**，不要两边都饱和。

## 六、关于"像不像参考"

参考视频是**俯视浅水**（水面占满画面），我们的两个主场景是**平视全景**。
构图不同，所以"整幅相似度"这类数字意义有限。

真正能逐项对齐的是**观感要素**：
深蓝的天 ✓、成团且会飘的云 ✓、青绿且有深浅分层的海水 ✓、浅米白的沙 ✓、
礁石有明暗 ✓、棕榈深绿有层次 ✓、水面有波纹但不油腻 ✓。

剩下的是**模型精度**层面的差距（低模石头、柱状云模型），这属于下一步的大件。
