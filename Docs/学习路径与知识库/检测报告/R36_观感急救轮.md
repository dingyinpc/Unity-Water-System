# R36 观感急救轮 —— 水的流动感 / 云的流动 / 画质（用户批词直答）

> 2026-10-25 夜。用户批词："水的流动感、云、画质、云的流动，这些全都没有做好"。
> 本轮不做大结构，三件事全部参数/设置级，全部实测验证、全部可逆（Tools/R36/90~92 + b 系还原）。

## 人话版小结

批词三条全部落实，每条都有实测数字：

1. **云的流动**：云层在 900~2000 米高空，原来的风只给 15 米/秒——换算到画面上约等于不动（实测云带 3 秒位移≈0 像素）。把风速提到 5 倍后，实测 **3 秒 64 像素**的清晰流动。Islet 热带天空的漂移也提了 3 倍。
2. **水的流动感**：海岸涌浪的速度倍率被历史调到 0.45（浪在"爬行"）。回到 0.95 后，实测白帽带 **3 秒 41 像素**的行进——R32 做出的"一排排白线"现在会明显朝岸走，流动感直接可读。皮肤纹理流速/冲滩节奏同步加快。
3. **画质**：查实**全项目从立项起就没开任何抗锯齿**（URP MSAA=关）——几何和水线的锯齿就是"画质没做好"的实锤。已开 MSAA 4×（实时视图和构建生效；离线量测工具不受影响，判据口径不变）。

## 与参考带的一个**有意分歧**（记档）

参考视频 S13 的云 3 秒全局位移≈0（R1 量测：原地翻腾为主）。本轮把云调到"看得见地流动"是**按用户观感偏好偏离参考带**（sky v ρ39 超带即此来源）。结论：参考带管"像不像视频"，用户观感管"像不像真的"——冲突时听用户的，但两边都记录。

## 踩坑记档

1. **离屏采集看不到 MSAA**：Seq/95 的离屏 RT 是单采样的，MSAA 只作用实时 Game 视图与构建——所以锯齿对比在序列帧上测不出差异（0.613→0.598 假阴性）。验证 MSAA 要看资产值+实时视图，别用离屏判据。
2. **FFT 场景测云位移测错了带**：该机位天空只占顶部 ~5%，我取的 0-250 行大半是水——互相关 0px 的"云不动"一半是测区错误。测云先确认天空带行范围（行均值直方图可判）。
3. **编辑器失焦时 Play 循环停摆会把"完全相同的两张图"喂给你**（本轮 95 静帧相关 1.0 的乌龙）——动效结论一律以**泵采序列**（91+94）为准，静帧只看形态。
