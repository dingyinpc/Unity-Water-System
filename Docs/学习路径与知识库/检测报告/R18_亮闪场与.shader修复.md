# R18 · 亮闪场（镜面耀光）+ 五 shader 修复链

> 2026-10-24。**人话版**：给五个水面加了"亮闪场"——随波演化的一粒粒太阳耀光点，
> 这是参考水面能量里缺失的最后一块内容级拼图。**Main 的水面能量从 0.489 冲到
> 0.761，第一次进入达标带**。过程里摔了一大跤：批量插入把五个水 shader 的函数
> 签名和函数体搅在一起，全部渲染成静止的灰回退画面——表面上像"引擎冻结了"，
> 排查了一圈（时间缩放/编辑器重启/GameView 双通路/红染与光源分测）才定位是
> shader 损坏，全部缝合并验证复活。Pond/Pool/Islet/Ocean 停在 0.29~0.37 平台：
> 亮闪场的镜面锥没有扫过它们的水面（Main 恰好扫过）——对齐需要逐场景调太阳/机位，
> 与"太阳方位取舍"是同一族决策，留给你用 Tools/Sky/93 演示开关拍板后一起做。

## 1. 交付

- **Sparkle 亮闪场**：`float Sparkle(xz,t,N,V,sun)` 加入五水面——噪声离散化亮斑
  （smoothstep 阈值门控）× 镜面方向锥（pow(dot(rv,sun))）× 光色，随微光场时间漂移
  演化（连续高光给不出 E，R16 饱和结论的内容级补齐）；
- **Main 水面四判据**：E **0.489→0.761 PASS（首次入带）**，D4 过；spk/v 带外
  （尖峰族+平移族，归因不变）；
- Pond/Pool/Islet/Ocean：+0~15%（镜面锥未覆盖水面），平台 0.29~0.37 记档。

## 2. Shader 损坏事故全记录（本轮最大教训）

1. **两次同型事故**：批量插函数时以"签名行"做锚点，函数体被插进签名与 `{` 之间
   （R16 修过一次，R18 换个姿势又踩）；换位手术又把两段签名/函数体交织成三明治；
2. **表象极具迷惑性**：shader 编译失败→URP 渲染静止灰回退画面→连拍逐位相同，
   看起来像"时间冻结/引擎停摆"。排查路径：timeScale→编辑器重启→GameView/Seq 双
   通路交叉→FFT 对照（未受损场景一切正常）→场景加载后的**增量日志**（此前的日志
   检查窗口早于变体编译，全部漏报）；
3. **修复**：五文件逐一段落重建（Sparkle 独立函数体 / ShimmerN 签名复位 /
   ValueNoise 孤儿体缝合 / Ocean 的 FogBank 前置声明），全部验证动画恢复
   （Main 帧0vs50 = 34.3）；
4. **红染/光测分测法**（新沉淀）：`col += float3(0.35,0,0)` 验调用链 →
   `col += mainLight.color*0.3` 验光源 → 两步把"零贡献"拆成可判定的三选一。

## 3. 工程守则新增（给下一会话）

- **shader 批量插入永远用"完整函数+闭合体"做单元**，锚点必须含函数体末尾；
- **shader 改动的错误检查必须在场景加载之后**（变体按需编译），日志检查先标偏移；
- 亮闪场的密度阈值（0.96→0.80）与锥角（24→6）是每场景独立定标项，不是全局常数。

## 4. 状态

Main 水面 E 入带后，六场景动态达标面：FFT 4/4、Main 水 3/4（E/D4 过）。剩余
Pond/Pool/Islet/Ocean 的能量平台需要镜面锥对齐（太阳方位/机位族，等 SKY93 拍板）。


## 5. 追加轮（方位带门控 / 亮斑闪烁提速 / 终态）

| 改动 | 结果 |
| --- | --- |
| 镜面锥→太阳方位带门控（lerp(0.35,1.4,方位点积)） | Pond +8%；其余不动（非瓶颈） |
| **亮斑漂移 ×4**（0.35→1.4 格/s：微光慢速塑形、亮斑独立快闪=真实耀光） | Pond 33→**44.7**；Main 稳 85；Pool/Islet/Ocean 不动 |
| Pond 增益 2.2→3.2 | +0.011 即饱和——剩余 13% 是水底亮度对比度（结构性） |

**终态**：Main **0.756 PASS**（三次复测稳定）｜Pond 0.435（差 13%）｜Pool 0.331/Islet 0.344（亮水/剪影构图，亮斑无对比度可用）｜Ocean 0.294（雾）。
附带收获：Pool/Islet 的 D4 主频转过、四场景 spk 过。亮闪场三要素（密度阈值/门控/闪烁速率）为每场景独立定标项。
