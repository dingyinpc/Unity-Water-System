## 2 我方现状（实施前）

- 雾：只有 URP 的 `MixFog`（线性/指数，屏幕空间近似），**不参与光照**、不影响水面高光。
- 云影：**完全没有**（天空有云，但云不投影到水面）。
- 水面高光/碎闪：只受主光方向与菲涅尔影响，与天空云层无联动。

## 4 补齐实施

### 4.1 云影（S14）

- 新增 `AtmosphereField` 组件 + shader：在 `_AFRect`（世界 XZ 域）内烘一张云影透射率图
  - 用与 `Sky_Coast` 同构的 **3 倍频 fbm**（4 倍频在 RT 上会退化成椒盐噪点，实测）；
  - 沿**太阳方向**投影（太阳越低影子拉得越长）：`proj = worldXZ - sunDir.xz*(H/sunDir.y)`；
  - `cloud = smoothstep(cover, cover+0.14, f)` → `trans = exp(-cloud·optical)`（Beer–Lambert）写入 R。
- `Water_Ocean` 按世界 XZ 采样（带边缘 smoothstep 防锐边），把透射率用于：
  1. 直射漫反射 `mainLight.color·ndl·0.30·sunAtt`；
  2. 太阳碎闪 + GGX 镜面 `× sunAtt`；
  3. **反射的天空色**：云下天空更灰 → `skyCol` 向灰白过渡。

### 4.2 远景雾（S15）

- 在水面 shader 内做**解析高度雾**（Beer–Lambert）：
  `opt = density · distV · 0.5·(exp(-(hCam-base)·falloff) + exp(-(hSurf-base)·falloff))`，
  `col = lerp(fogColor, col, exp(-opt))`。
- **雾遮太阳**：`fogVis = exp(-_FogDensity·_FogSunLen)`；与云影串联 `sunAtt = cloudTrans·fogVis` → 衰减水面高光/碎闪。

### 4.3 参数唯一写入点

- 云影图参数（域/云尺度/量/厚度）在 **`AtmosphereField` 组件**（场景序列化）。
- 耦合开关与雾参数在 **`Ocean_Water.mat`**。
- 菜单 170~177 只负责写这两处。

### 5.1 实测

| 档 | RGB 均 | 变化像素 |
| --- | --- | --- |
| 雾 关 | (170.5,102.8,91.5) | — |
| 雾 开 | (170.1,104.5,93.8) | 11.10% |
| 云影 关 | (170.5,102.8,91.5) | — |
| 云影 开 | (170.5,102.8,91.5) | 0.04% |

### 5.2 为什么云影只有 0.04%（定量归因）

1. **云影图本身大部分是晴空**：自然参数下透射率均值 **0.899**（最低 0.537）→ 可见水面上多数像素 `cloudTrans≈1`。
2. **本机位太阳很低**：水面直射漫反射 ≈0、GGX 高光 ≈0（与 P0-2 的 Ocean SSR 同性质）→ 云影能衰减的"直射"几乎没有；
   这也是为什么把云影也接到"反射天空色"和"天光份额"上，才得到 0.04% 的可测变化。
3. **可见水面只占画面一小条**：即使强制云影到 0.25（极端），全屏也只有 0.88% 像素变化 → 上限就在这。

> 结论：**机制成立且确实到达水面**；"看不出来"是**本场景/机位/时刻**的问题，不是代码没接。
> 想看到参考视频那种"云飘过、水面高光整片变暗"，需要：太阳更高（正午档）、水面上方有云、或把云量调高。

### 5.3 人话版小结

- **云影**：给水面加了一张"云的地图"。云挡在太阳前面时，水面的亮光和倒影会变暗/变灰。实测发现：代码是通的（强行把云影调黑，水面确实变暗 0.88%），**但这张地图在可见水面上方基本是晴的**，加上此刻太阳很低，所以自然档下只有 0.04% 的变化——就像"阴天"没落在你面前这摊水上。
- **雾**：给远处加了一层"会吃光的空气"。越远越白、越白越看不到，而且这层雾**自己也会挡太阳**——雾浓时水面的太阳高光跟着变暗。实测开关雾，画面 **11.1% 的像素**变化，效果明显。
- **一句话**：雾做成功了；云影接线成功，但要更换机位/时刻或调高云量才能"看见"。

## 6 遗留与风险

1. ⚠ **S14 未达到"肉眼明显"**：需要正午高太阳 + 水面上方有云。建议后续加一个"云影演示档"（把云量/云影强度临时拉高 + 机位抬高）。
2. ⚠ **雾是解析高度雾，不是参考的 3D 噪声 raymarch**：没有"雾团"结构，只有高度/距离梯度；代价低但观感更均匀。
3. ⚠ **雾只作用在水面**（在 `Water_Ocean` 里），没有覆盖地形/天空（未做 URP RenderFeature 全屏体积雾）→ 远景岩石/树不会被雾吃掉，与参考 S15 有差距。
4. ⚠ **云影图是"世界 XZ 投影"而非屏幕空间**：参考按屏幕空间；我们按 S14 文字里的"水面世界XZ映射"实现，更稳定但与参考实现有差异。
5. ⚠ **太阳方向来自 `RenderSettings.sun`**：`DayNightCycle` 切时段后需重建（组件每帧 Render 会重算方向，已自动跟随）。
6. ⚠ 性能未测：云影图 256²/帧 + 水面每像素多 1 次纹理采样。

## 8 复检（2026-10-20）：雾统一 + 云影可见性修复

> 触发：P2-3 是路线表里**唯一还挂 ⚠️** 的一项，复检时又发现两个真 bug。

### 8.1 真 bug ①：场景雾色是上一轮"黄昏"的残留

场景里 `RenderSettings.fogColor = (0.95, 0.42, 0.32)`（红色），而水面材质的 `_FogColor` 是写死的
灰蓝 `(0.72, 0.78, 0.82)`，密度也各写一套（场景 0.0022 / 水面 0.012）。
后果：**正午时远景地形被染成红色，水面却是灰蓝**，海陆交界出现色相断层。

**修法（单一真源）**：`DayNightCycle` 新增 `driveFog / fogDensity` 两个字段，`Apply()` 里一次写三处：

| 写入点 | 值 |
| --- | --- |
| `RenderSettings.fogColor` | 地平色 |
| `RenderSettings.fogDensity` | `fogDensity`（0.0022） |
| 水材质 `_FogColor` / `_FogDensity` | 同上两项 |

### 8.2 真 bug ②：水面雾公式与 URP 雾**不同式**，且叠了两次

- 旧水面雾是 `exp(-density·dist)`（线性 Beer–Lambert），URP 场景雾是 `exp(-(density·dist)²)`（Exp²）。
  同一距离两者差一个数量级 → 水面比地形雾得多。
- 旧代码末尾**无条件** `MixFog()`，开解析雾时等于叠两次。

**修法**：水面解析雾改成**与 URP 同式**（`exp(-fd²)`，高度只留 `sqrt(dCam·dSurf)` 的温和系数），
并用 `if (_FogOn < 0.5) MixFog(...)` 避免重复。

### 8.3 真 bug ③：云影耦合对亮天空近似恒等变换

旧代码：`skyCol = lerp(skyCol, skyCol*0.72 + 0.22, sh*0.9)`。
对亮天空 `0.75*0.72+0.22 = 0.76` → **几乎是同一个颜色**，所以云影 A/B 只有 0.04%。

**修法**：乘性变暗 + 去饱和
```hlsl
float sh = saturate(1.0 - cloudTrans) * _CloudShadowStrength;
float3 greySky = dot(skyCol, float3(0.299,0.587,0.114)).xxx;
skyCol = lerp(skyCol, greySky * 0.70, sh * 0.65);
```

### 8.4 实测（冻结 · 同一 Play 会话）

| 项 | 修复前 | 修复后 |
| --- | --- | --- |
| 雾 关/开（自然档 0.0022） | 11.10%（旧公式 0.012，与地形不一致） | **1.15%**（与地形同式同密度，视觉一致） |
| 雾 关/开（S15 演示档 0.0035） | — | **3.66%** |
| 云影 关/开（黄昏） | 0.04% | — |
| 云影 关/开（正午，修复前） | 0.66%（max 24） | — |
| 云影 关/开（正午，修复后） | — | **1.75%（max 44）** |

> 云影 4.4 倍提升（相对黄昏档 0.04% → 16 倍），且最大通道差从 24 升到 44，肉眼已能看到水面明暗斑。

### 8.5 人话版

- **雾**：以前水面和陆地各用一套"雾"，结果远处山被染成红色、水面却是灰蓝，接缝很假。
  现在改成**同一套雾、同一个颜色、同一个浓度**，并且白天转黑夜时雾色自动跟着地平线走。
- **云影**：以前代码是通的，但"云挡住太阳→水面变暗"那一行写错了，算了等于没算（亮天空下前后颜色几乎一样）。
  改成"按比例压暗 + 去色"之后，正午水面能明显看到云影走过的暗斑。

### 8.6 复检后仍存在的差距

1. ⚠ 云影幅度仍受**机位**限制：视线越掠射，水面颜色越由"反射天空"主导，而云影只压暗反射的一部分。
   参考视频里那种"整片水面忽然暗下来"需要**俯视机位/更高太阳**才明显。
2. ⚠ 雾是**高度+距离**的解析式，没有参考的 3D 噪声"雾团"结构。
3. ⚠ 雾对天空盒无影响（天空自己在地平线处已经是雾色，视觉上连续，但不是真正的体积雾）。
4. ⚠ 性能未测（云影图 256²/帧 + 水面多一次采样 + 雾为解析式，开销很小）。
