## 4 补齐实施

### 4.1 设计（三元模型，照参考 `08` S10）

| 环节 | 做法 | 落点 |
| --- | --- | --- |
| **① 生成** | 源 = 碎浪带(最浅水×湿) + 冲浪带×(水面**曲率** + **坡度** + 流速超阈值) × **丝缕噪声** | `ShallowWaterSim.shader` Pass 3 |
| **② 平流** | 半拉格朗日：`prevUV = uv − vel·α·dt / domainSize`，读上一帧 `_SWFoamPrev` | 同上 |
| **③ 衰减** | `foam *= exp(−decay·dt)` | 同上 |
| **④ 合成** | 水面按世界 XZ 采样 `_SWFoam`，过"阈值膝"后叠进总沫量 | `Water_Ocean.shader` |

参数唯一写入点：**生成参数**在 `NearshoreFlowSim` 组件（场景序列化，逐帧喂 shader）；**合成强度/阈值**在 `Ocean_Water.mat`（水材质属性）——两层各管一段，不重复。

### 4.2 新增/修改文件

- `Assets/Art/Shaders/ShallowWaterSim.shader`：新增 **Pass 3 `SWFoam`**（+ 噪声 Hash12/VNoise）；Viz Pass 增**模式 5 = 泡沫密度**。
- `Assets/Scripts/Logic/NearshoreFlowSim.cs`：泡沫 ping-pong RT（ARGBHalf，与状态同尺寸）；`StepFoam()` 每模拟步推进；全局暴露 `_SWFoam`；`RenderViz(5)`。
- `Assets/Art/Shaders/Water_Ocean.shader`：属性 `_FoamHistStrength(0.6)`、`_FoamHistBias(0.3)`；采样 `_SWFoam`。
- `Assets/Editor/NearshoreFlowSetup.cs`：菜单 **140 泡沫历史=0 / 141 =1 / 142 还原0.6 / 143 导出泡沫密度场 / 144 再推进300步并导出**。

### 4.3 两次"翻车"（值得单记）

1. **只按浅水生成 → 一块均匀白板**：初版把浅水当生成源、又没卡阈值，稳态下 `生成/衰减 ≈ 1`，整个冲浪带饱和（34% 像素满值）。修：生成源乘**丝缕噪声** + 复合端加**阈值膝**。
2. **深水涌浪也在产沫**：初版浪峰曲率/坡度不分深浅 → 外海也一直产沫，海面糊白。修：所有生成统一乘"冲浪带权重" `shoal = saturate(1 − depth/ShoreD)`。

### 5.1 人话版小结

- **做了什么**：给海面加了一张"泡沫记忆纸"。浪在哪里碎，就在纸上点一片白；这张纸每帧**按水流方向把白点往前推**（泡沫随水飘），同时**慢慢变淡**。水面再回头看这张纸：纸上白的地方就画白沫。
- **为什么参考视频的泡沫"好看"**：它的白沫不是一闪就没，而是**留痕**——浪过去了，泡沫还在原地漂一会儿才淡掉。我们以前是"浪一过、白沫立刻消失"，所以看着像闪片。
- **怎么知道做对了**：① 把这张纸多推进 5 秒再翻出来看，图案**变了**（说明它真在随时间演化，不是每帧重新画的）；② 把泡沫记忆**关掉/打开**各截一张冻结图，画面差 8%（说明水面确实读了这张纸）；③ 纸上白沫**只在岸边浅水**，外海干干净净（没有把整片海糊白）。
- **踩的两个坑**：第一版把整片碎浪带填成一块白板；第二版连外海的浪也在产沫、海面发白。都已修（加噪声丝缕 + 只在碎浪带生成 + 合成时卡阈值）。

## 6 遗留与风险

1. ❌ **未接 Main（`Water_Advanced`）**：Main 的水塘没有流场/泡沫 sim。要接需给 Main 也建一份（或抽出独立 `FoamHistoryField` 组件），本轮只在 Ocean 落地。
2. ⚠ **"浑浊度"权重是近似**：C20 要求"浑浊度 × 流速阈值"，本轮用"浅水深度"当浑浊度代理，未做真正的浊度场。
3. ⚠ **泡沫着色仍用常量 `_FoamColor`**：C20 提到"结合主光与环境光照上色"，本轮未做（仍用固定近白色）。
4. ⚠ **去平铺（C18/C20 复用 S8 焦散的三角偏移混合）未做**：本步用噪声丝缕代替，够用但非参考做法（将来与 S8/P2-2 一起抽 helper）。
5. ⚠ **性能未测**：每模拟步多 1 个 pass + 水面多 1 次纹理采样；256² 泡沫 RT。待 Play 探针 FRAME ms。
6. ⚠ **`DayNightCycle` 每次进 Play 会把颜色写回材质**：所以 Ocean 的两张 `.mat` 每跑一次 Play 就"变脏一次"（本轮已把 P1-2 提交里的颜色churn 还原，只留泡沫两属性）。属 P1-1 既有行为，记录以免下次误判为"谁改了材质"。
7. ⚠ 泡沫密度场是**域内**的（840×240m 海岸矩形）；域外水面无残留泡沫（回落到既有瞬时泡沫）。
8. ⚠ 固定步长：泡沫随模拟步（`simHz=60`）推进，与参考"统一时钟"的 60Hz 固定步一致；但 `Update` 里有 `guard<8` 的追赶上限，极端卡顿时会慢放（与整个模拟一致）。
