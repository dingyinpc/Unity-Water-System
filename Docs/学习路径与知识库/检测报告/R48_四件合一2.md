## 1 ① 先纠错：那条"竖缝"根本不存在

R47 报告里我写了「白点去掉后泻湖露出一条竖缝（5.29@443）」。这轮先验证它：

| 测量范围 | seam 尖峰 | 结论 |
| --- | --- | --- |
| 全图 | **5.29 @443** | 看着像缝 |
| **只取纯水面带（0~110 行）** | **2.75 @457** | 正常噪声水平 |

再打印 435~451 列的梯度剖面：`5.4 4.1 4.2 4.5 4.6 5.5 7.8 8.1 10.9 7.8 5.8 7.6 6.1 5.1 5.3 6.2 8.9`
—— 是一个**宽缓的峰**（沙洲边缘），不是 1px 尖线。

⇒ **这是量具把"沙洲的左边缘"认成了竖缝**。R47 §0 的那条结论作废。
**量具教训**：`seam` 只能在**同质区域**（纯水面）上测；画面里有强边缘时它会误报。

## 2 ② 沙洲纹理：真因是贴图，不是平铺频率

第一反应是放大 tile（2.6m → 7.5m）。实测**更糟**：

| 版本 | 摩尔纹 |
| --- | --- |
| 原样（tile 2.6） | 0.183 |
| 放大 tile 后（7.5） | **0.208（+14%）** |

于是去看贴图生成代码，发现 `Islet_SandDry` 里有一项：

```csharp
float dune = Fbm(u * 0.9f, v * 0.9f, 3);   // 每张 512 贴图里只有 1 个大包
float k = 0.47f + 0.05f * dune + ...
```

**低频内容 + 平铺 = 规则网格**。放大 tile 只会把网格拉大，不会消失 —— 与实测一致。

**修法**：重生成沙贴图，把低频 dune 压到 1/6：
`0.05 → 0.008`（干沙）、`0.10 → 0.015`（湿沙），同时把高频颗粒/细沙纹略加强（近景质感靠它们）。

| 指标 | 改前 | 改后 |
| --- | --- | --- |
| 摩尔纹 | 0.211 | **0.170（−19.3%）** |
| 亮度 | 145.7 | 136.4（−6.4%） |
| 视觉 | 规则"绗缝" | **绗缝消失，沙面平整** |

> 注：另有一版压得更狠（摩尔纹 −46.7%），但亮度掉 13%，湿沙发暗；取了折中档。
> 还原：`git checkout -- Assets/Art/Textures/Islet/Islet_SandDry.png Islet_SandWet.png`

- 石头偏小（0.3~1.4m），在参考里礁石是明显的地标物；
- 珊瑚偏白（三种配色材质已建，但当前尺寸+曝光下读不出颜色）。

## 4 ④ 解析抗锯齿（fwidth）

原来只按**距离**淡出（距离是代理量）。这轮加真正的解析 AA：

```hlsl
float fp   = length(fwidth(Ns));                 // 这一像素内法线变化多少
float aaF  = saturate(fp * 90.0);
float glPow = lerp(lerp(_GlitterPow, 80.0, distFade), 20.0, aaF);
```

**无法单独验证**：本轮沙洲贴图、礁石材质同时改了，`点硬度` 的读数（0.48）无法归因到 AA。
下轮补一个"AA 开/关"开关做纯净 A/B。

## 6 遗留

1. **水面域边界黑楔**（R46 就发现，本轮到 R48 仍未修）——左上角大三角，浅水模拟域边界没有过渡；
2. 礁石**尺寸**要放大到 1~3m 才有"地标感"；
3. 珊瑚**配色**要压住白（或在材质里降 smoothness / 提高饱和）；
4. **AA 的纯净 A/B**（加一个 `_GlitterAA` 开关）；
5. 沙洲亮度还差 6.4%，可把湿沙基色再 +0.01。

## 7 人话版

- 上一轮我说"水面露出一条竖缝"——**是我量错了**。只在纯水面区域量，那个数字就正常了；高的那个是**沙洲的左边缘**被量具当成了缝。这条作废。
- 沙洲的"绗缝花纹"：先试着把贴图放大，结果**更明显**；查代码才发现是贴图里每张只有**一个大包**，平铺后就成了网格。把低频包压掉、保留细颗粒，花纹就没了。
- 礁石换成灰褐色的新材质（原来那套是给崖体用的，在这里渲染成纯黑），珊瑚从"球堆"改成"有枝杈的树杈"。
- 白点的抗锯齿从"按距离"升级成"按像素足迹算"（fwidth），但这一轮没法单独量它的效果——要下轮补个开关。
