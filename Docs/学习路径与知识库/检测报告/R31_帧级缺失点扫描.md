## 人话版小结

七组并排判完，相似度排序：**Islet 7/10 → FFT/Ocean/天空 6/10 → Pond 5/10 → Main 4/10**。判出来的缺失点高度集中——不再是"效果没做"，而是**形态学差距**（形状/分布/尺度不对）：浪峰没有白沫和尖峰、焦散网太细密（参考是大块稀疏）、泡沫该沿浪线成带（我们是斑点状）、云底缺阴影、水下缺植被内容、反射碎而不连。这些每一项都有现成的技术底座（白沫有 Jacobian 场、焦散有多尺度参数、泡沫有历史场），缺的是**形态参数没对到参考的形状**——正是下一轮的可执行清单。

## 2 归类与建议优先级

- **参数形态轮（一轮可收，预计收益最大）**：FFT 浪尖白沫/尖峰/海色/焦散尺度 + Ocean 泡沫带状化/长直浪 + Pool 焦散大块化 + 云底阴影——全部有现成底座，纯参数与权重；
- **内容资产轮（要放东西）**：水下植被石头（Main/Pond）、远景岛剪影（Islet）、FFT 云天空；
- **专项验证**：昼夜/夜空分时对照（白天档对照不到，需按 S11 时段捕获）；
- 与已关闭项交叉：无冲突（本轮全是形态/内容层，此前关闭的是噪声/斜率/构图层）。
