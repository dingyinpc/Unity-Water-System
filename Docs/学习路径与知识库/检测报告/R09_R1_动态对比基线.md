# R09 · R1 动态对比基线 —— "3 秒逐帧对比"量具落地 + 五场景首轮判定

> 2026-10-24。《10_完全复刻策划案》R1 交付物。**人话版**：我们造好了"量动画的尺子"——
> 把我们的画面和 UP 主的画面各截 3 秒逐帧对比，量四件事：动得多不多（运动能量）、
> 有没有跳变（连续性）、东西挪多快（速度）、闪的节奏（频率）。尺子先拿 UP 主
> 的视频自己对自己量了一遍，确认量得准（比值全≈1）。然后量了五个场景，结论：
> **云是最大短板**（我们天上的云几乎不动，运动量只有 UP 主的 1.4%，速度慢 5 倍）；
> **多数水面太"死"**（动起来的能量只有 UP 主的 12%~33%）；**而贴图滚动的速度反而
> 过快**（是 UP 主的 7~20 倍——"匀速滚图"不等于"活的水"）。这些数字就是下一轮
> FFT 海洋（R2）和体积云（R3）的调参靶子。

## 2. 量具自证与校准记录（先于一切结论）

1. **参考对参考**（同一段既当"我方"又当"参考"）：ρ_E/ρ_v/ρ_f 全 ≈1.00 PASS——量具自身无偏。
2. **D2 阈值校准**：90 帧窗口的自然重尾使参考自身的 max/σ 就有 3.3~4.1，"绝对 <3"连参考都过不了
   ⇒ 判据改为"我方 < max(3, 1.2×参考)"（孤立爆闪仍会现形，参考自身的尾部不算罪）。
3. **采样率偏置**：同一内容隔帧采样（15fps）对 30fps 的 ρ_E≈0.83——|ΔI| 累积对时间是次线性的。
   我方 20fps 对参考 30fps 的偏置 ≈ −10% 量级，判据带宽（0.5~2.0）足够吸收；报告数字未做校正。
4. **D3 测速法更替**：全幅相位相关被静景淹没（1 秒后相关峰 0.8 仍在原点——山/天空渐变占大头），
   ⇒ 改"时间差分热点 × 模板匹配"：先找动了的块（前 3 个热点）再跟它，多对帧（间隔≈1s）取中位；
   参考侧按 `cuts.json` 剔除跨切镜配对。烧录 UI（标题/字幕）随热点法自然规避。
5. **ROI 语义警告**：ROI 按画幅比例切（sky=上 42%，water=下 52%）——**机位不同 ROI 内容不同**
   （Islet 俯角大，"sky"带里其实有水和岛）。跨场景横向比较时以 water/full 带为准，sky 带只在
   "相机类似"的对里解读（Ocean↔S13 最典型）。

## 4. 差距排行（R2/R3/R4 的调参靶子）

1. **天空/云——最大短板，R3 主靶**
   - Ocean↔S13：我方天空像素能量 **0.9/s vs 参考 66.7/s（1.4%）**——2D 噪声贴图云近乎静止，参考体积云持续演化；
   - 云速 **0.15 vs 0.84 %画宽/秒（慢 5.6 倍）**——用户"云的速度位置有大问题"的定量实锤；
   - 参考 S13 段云速基准 **0.84 %W/s**（%画宽/秒）＝R3 体积云风速的定标锚点。
2. **水面运动能量——普遍偏死，R2 主靶**
   - Pond 0.12 / Ocean 0.20 / Islet 0.28 / Pool 0.33（Main 0.91 达标）；
   - 根因方向：参考是 FFT 多级海——频谱随时间演化、波形成分持续变化；我们是**静态噪声图滚动**，
     滚得再快像素能量也上不去（见第 3 条的反常组合）。
3. **"滚图过快"反常组合——直接调参可收**
   - Ocean 水面平移 4.2 %W/s vs 参考 0.6（**7 倍**）；Main 2.49 vs 0.12（**21 倍**）；
   - 动画节奏（ρ_f）普遍 1.5~2.5 倍过快：Pool 焦散 1.33Hz vs 0.67、Pond 1.67 vs 0.67；
   - ⇒ R2 之前的快速止血项：把各水面的流动/焦散时间倍率降到 ~0.5×（一行参数，收益立现）。
4. **Main D2 尖峰**——交互演示（autoDemo 大涟漪）造成的孤立亮度跳变；播放节奏改缓即可。

- R1 三件套落地并自证，五场景基线入表——**R1 验收三条全过**（工具跑通五场景 ✓ / 四判据数值+比值 ✓ / 云速差距实测 0.15 vs 0.84 ✓）。
