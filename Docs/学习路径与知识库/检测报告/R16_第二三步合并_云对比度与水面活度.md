## 4. 工程坑（本轮新记）

- 批量插函数时 anchor 串只含签名行 ⇒ 函数体被插进签名与 `{` 之间（三处编译错）；
- shader Properties 默认值改动追不上已序列化的材质值（Ocean _ShimmerAmt 钉在 0.4）；
- check_shell/check_compile 的 log 截取含历史错误行——判"当前态"必须先标日志偏移再刷新。
