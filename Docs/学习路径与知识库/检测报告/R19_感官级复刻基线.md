# R19 · 感官级复刻 —— 量具与基线（复刻范式扩展）

> 2026-10-24。**人话版**：用户指出了要害——此前是"功能+动态判据"复刻，但画面的
> **感官质感**（精细程度、噪点、颗粒）从没被测量和复刻。这轮把"质感"变成了四把尺：
> 结构相似度、噪声频谱斜率、微对比分布、高频能量占比，六场景全量了基线。
> **数字证实了判断**：我们的画面系统性"太干净"——频谱斜率全线比参考陡（CG 光滑），
> 高频能量最差只有参考的 4%（泳池），纹理密度只有参考的 1/3。第一次对症尝试
> （URP 胶片颗粒）量出 +6%——单像素颗粒在对比降采样中被抹掉，且泳池的真实缺口
> 是材质细节密度而非纯噪声。这轮是感官复刻的开题：尺已立、靶已量化、下轮开修。

## 1. 四把尺（perceptual_compare.py）

| 尺 | 量什么 | 判读 |
| --- | --- | --- |
| S1 SSIM | 结构重合度 | 构图不同时天然低（本用途弱，仅参考） |
| S2 频谱斜率 | 径向功率谱 log-log 斜率 | 自然图像 -2~-3；越平=颗粒重、越陡=CG 光滑 |
| S3 微对比 p50/p90 | 8×8 块局部 std 分布 | 纹理/细节密度代理 |
| S4 高频占比 | Laplacian 能量/总能量 | 颗粒+锐度的综合 |

## 3. 首次对症实验（URP FilmGrain 0.35/Medium4）

S4 仅 +6%（0.0067→0.0071）。**两个发现**：
1. URP 颗粒是输出分辨率单像素级——在 1080p→432p 对比降采样中被平均掉；参考的
   噪声活在它自己的原生分辨率上（观看尺度更大更可见）。**要对齐"观看尺度"的颗粒
   需要自定义后处理**（2~3px 尺度的时序噪声），不是现成 FilmGrain；
2. Pool 的 S3（纹理密度）缺口与 S4 同量级——纯颗粒补不满，**需要材质/焦散的
   高频细节加密**（同 R2 焦散三版迭代的教训：细结构的对比度才是感官主体）。

## 4. 下轮路线（感官复刻 R20，待继续）

1. 自定义颗粒 pass：2~3px 时序噪声（匹配参考频谱斜率 -2.0~-2.3 目标），作用于
   全场景后处理栈；
2. Pool 焦散/瓷砖高频加密（S3 14→35+）、Ocean 水面远场微纹理、Islet 植被细节；
3. 每步用 S2/S3/S4 复测——感官复刻从此和动态判据一样有数可依。
