## 4 补齐实施

### 4.1 设计（唯一旋钮）

`DayNightCycle` 用 **一个 0~1 的 `timeOfDay`** 同时驱动：

| 输出 | 规则 |
| --- | --- |
| 太阳角度 | `elev = sin((t−0.25)·2π) · 75°`（日出 0° / 正午 +75° / 午夜 −75°），方位沿用调好的 236° |
| 太阳强度 | `SmoothStep(elev/18°) · 2.9` |
| 月亮 | 方向 = 太阳反相（方位 +180°），强度 = `SmoothStep(−elev/18°) · 0.30` |
| 天空顶/地平/地面 | 5 条**颜色曲线**按 t 采样（地平做地面半色） |
| 云色 / 云底阴影 | **按"日照因子" `day=saturate((elev+6)/26)` 在"夜色↔白"之间过渡** |
| 日晕强度 | `1−|elev|/45°` 归一（太阳越低晕越大） |
| 雾色 | = 地平色（地平线不留硬边的唯一条件） |
| 水色 | `_SkyZenith/_SkyHorizon/_DeepColor/_ShallowColor/_SunColor` 全部随曲线 |
| 环境光 | 保持 Skybox 模式 + **`DynamicGI.UpdateEnvironment()`（节流）**，天光自然跟着天空变色 |

**关键取舍**：
- 天空 shader 用 `GetMainLight()` 取太阳方向（`Sky_Coast` 自带约定）⇒ **不再同步第二份太阳角**（避开《05》C-4）。
- 不再维护"环境光曲线"——让 Skybox 环境光跟着天空走，少一套互相打架的旋钮。

## 5 验收判据与结果（真机）

### 5.1 四个时段实测（冻结时间后截图，896×379）

| 时段 | 天空带 RGB | 水面带 RGB | 观感 |
| --- | --- | --- | --- |
| 正午 0.50 | (178, 203, 239) | (159, 181, 207) | 淡蓝白晴空 ✅ |
| 日出 0.28 | (212, 169, 174) | (186, 120, 114) | 暖粉晨光 ✅ |
| 黄昏 0.73 | (199, 126, 123) | (203, 97, 78) | **橙红云海 + 水面橙红反光带** ✅ |
| 午夜 0.00 | (5, 9, 20) | (11, 16, 36) | **深蓝夜色** ✅ |

- 四条时段互不相同且单调合理（昼夜→暖→暗），与参考 f3050/f3200/f3400 的**色相走向一致**。
- 回读探针（菜单 111）证明材质值真的写进去了：`天空 顶(0.240,0.120,0.360) 地平(0.950,0.420,0.320) 云(0.703,0.575,0.551) | 太阳 强度1.55 仰角9.4 | 月亮 强度0.00`。

### 5.2 人话版小结

- **做了什么**：给整个场景装了一个"时间旋钮"。转到早上，太阳升起、天空发白发蓝；转到黄昏，天空变橙红、水面跟着变红；转到半夜，天全黑蓝、太阳换成月光。
- **怎么知道做对了**：把时间**冻住**（不然波浪在动，截图对不上），分别转到四个时间点各截一张，量天空和水面的颜色——四个时间点的颜色完全不同、而且符合直觉。
- **顺带修了一个**：天气系统一开始"永远是白天"（天空全白），真因见 §5.3。

### 5.3 本轮踩的坑（值得单记）

**Unity 的 `Gradient` 字段在 MonoBehaviour 上会被还原成默认值**：本机实测，代码里刚赋好 9 个关键帧的 `Gradient`，
下一句读回 `colorKeys.Length == 2`、`Evaluate()` 恒为**白色** —— 表现为"天空永远是白的、昼夜没反应"。
排查过程绕了弯路（先怀疑材质为空、再怀疑云色公式），最后靠**回读探针**（把曲线自身的 key 数与求值结果写进日志）定性。
**改法**：颜色曲线改用**朴素 `Color[] + float[]` 数组 + 手写线性插值**（可序列化、行为可预测），不再用 `Gradient`。

**另一条**：云色最初写成 `lerp(地平色, 白, 0.75)`，夜里也几乎全白（整片天空发白）。
必须引入**日照因子** `day = saturate((elev+6)/26)` 做过渡。

3. ❌ **朝阳面/背阳面双套天空渐变**（参考 C24：`dot(view,sun)` 混合两组高度色）——未做（当前只有一套高度渐变）。
4. ❌ **太阳耀斑 LensFlare 平滑切换**（参考 C22/C23）——未做。
5. ❌ **体积云随昼夜改变受光**（参考 S13）——未做。
6. ⚠️ 自动循环（菜单 115）只是把 `timeOfDay` 线性推进，**没有"60Hz 固定步长"**；参考 C4 强调统一时钟，P1-1 用简版即可。
7. ⚠️ 每帧 `Apply()` 里 `DynamicGI.UpdateEnvironment()` 已节流（t 变化 >0.002 才更新），但**自动循环时仍会频繁触发**，
