# R37 S11 昼夜分时专项 —— 黄昏/夜晚从"全黑"到入带

> 2026-10-25 深夜。R31 遗留的最后一条对照线：昼夜段（S11=f3000~f3450）从未和参考比过。

## 人话版小结

参考视频 1:40~1:55 展示昼夜：白天→黄昏（橙霞映水）→夜（月光+水面月光带）。
我们切到黄昏/午夜：**整个天空黑掉**（亮度只有参考的 1/10），月亮在、沙滩亮着，但天空像没通电。

一步步排查（关夜因子→没用；关云→没用；关"云隙压深"→亮一点；**关后处理→天空满血复活**）：
元凶是**调色链（对比度+ACES）在低光下把已经很暗的天空压成纯黑**，帮凶是 R18 的"云隙压深"档（0.52 一刀切压全天时段）。

修法三件套：
1. 云隙压深改成**跟着昼夜走**——白天保持原校准 0.52（R18/R32 的成果不动），低光抬到 0.75；
2. 黄昏/深夜的**天空色曲线加亮 2.2 倍**（黄昏带 1.5 倍，头一版 2.2 过冲）——把亮度抬进调色链的活区；
3. 星星亮度 1.15→2.4、银河 0.45——之前根本过不了调色这关。

结果：**夜晚 39.8 vs 参考 36（几乎正中），黄昏 112 vs 98 入带**；盲看夜 **9/10**（月亮/星/银河/水面月光带全在）、黄昏 7/10（霞光集中在地平线、上部偏暗、水面暖反光弱于参考）。

## 踩坑记档

1. **黑盒定位四步法**（本轮价值最高的东西）：状态正确渲染全黑时，逐个"会话级解除嫌疑"——夜因子=0（无效）→云盖=0.05（无效）→SkyDeep=1（部分）→**后处理=关（满血）**。每步一张静帧，凶手无处躲。
2. **自己的乌龙**：96 试验把相机后处理关了没开回来，之后一整批"校准数字"全是无调色口径（黄昏 132 的假象）——**试验菜单必须成对（96c 开回来了）**，且 A/B 前先跑 99 读数确认口径。
3. **编辑模式下环境光烘焙会陈化**：DynamicGI.UpdateEnvironment 只在 Apply 菜单跑（Update 不执行），陈年暗烘焙一直压着白天——本轮刷新后天亮了 40%（正午 64→141，D 判据零回归，视觉无异常）。
4. ColorKey 字段名是 `c` 不是 `color`（猜错一次编译教做人）。
