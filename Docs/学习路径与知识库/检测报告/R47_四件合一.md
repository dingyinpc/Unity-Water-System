## 1 ① 水面白点：先证伪，再定位

第一版按常识改了 `Sparkle()`（亮闪场），加距离淡出。**同会话 A/B 结果：逐位相同（0.00%）**。

于是做了排除实验（同一会话，逐个关）：

| 实验 | 白点密度 | 结论 |
| --- | --- | --- |
| 基线 | 25.03 | — |
| `Sparkle` 全关（`_SparkleFade=(0,1)`） | 25.03（**逐位相同**） | ❌ 不是它 |
| `_GlitterStrength=0`（碎闪=0） | **6.75（−73%）** | ✅ **主源** |
| 再关 `_CapStrength`（毛细） | 6.71 | ❌ 不是它 |
| 再关 `_FoamStrength`（泡沫） | 7.78 | ❌ 不是它 |

**根因**：`Water_Lagoon` 的碎闪 `_GlitterPow = 420`——只有法线**几乎完全对准**太阳的像素才亮。
远处法线是亚像素采样，随机命中 ⇒ 整片水面变成随机白点。

**修法**（不是简单砍掉，而是标准高光 LOD）：

```hlsl
float glPow = lerp(_GlitterPow, 80.0, saturate(glDist / max(_GlitterFade.y, 1.0)));
float gl    = pow(saturate(dot(Ns, Hs)), glPow) * glF;   // glF = 距离淡出
```

近处保持 420（锐利碎闪），远处降到 80（同能量摊成柔光），最后按 `_GlitterFade=(18,75)` 收到 0。

**实测（最终档，同会话冻结）**：

| 指标 | 改前 | 改后 | 变化 |
| --- | --- | --- | --- |
| 白点密度 | 26.75 | **9.55** | **−64.3%** |
| 点硬度 | 0.78 | 0.38 | −50.4% |
| 亮度 | 146.6 | 145.1 | −1.0% |
| 对比 | 51.9 | 51.3 | −1.0% |
| 全画面差异 | — | — | 3.37% 像素（严格局部） |

参考帧基线：白点 52.78、硬度 0.09 ⇒ 我们**密度已经低于参考**，只差"硬度"（参考是软颗粒，我们是硬点）。

## 2 ② 沙洲扇贝纹：改对了文件，但改错了对象

给 `Beach_Sand` 加了距离 LOD：细粒（1.8cm）15m 外归零，换成 25cm 粗斑驳，60m 外也归零。

**但 Islet 的沙洲不是 `Beach_Sand`**——它是 **Terrain 图层的平铺贴图**。所以：
- 这条修复对 **Ocean 场景的沙滩**有效；
- 对 Islet 沙洲**无效**，图案还在（而且因为白点没了，摩尔纹指标反而 +42%，是"显影"不是"变差"）。

⇒ 正确修法在 Terrain 图层（`IsletTerrain` 的 LayerFolder 贴图 tiling），或者给沙洲单独一层 shader。**本项未完成**。

## 3 ③ FFT 竖缝：根因是"周期场用了 clamp"

`FFTOcean.compute` 的 `GradJacob` 求中心差分时写的是：

```hlsl
uint2 xl = uint2(max(id.x - 1, 0), id.y);        // ← 边界处步长被砍半
uint2 xr = uint2(min(id.x + 1, FFT_N - 1), id.y);
```

位移场是 IFFT 输出 ⇒ **天然周期**。边界 clamp 会让每条 tile 边界上的法线/泡沫断一次，
俯视时正好落在画面中心（uv=0 处）⇒ 一条竖线。

改成环绕：`(id.x + FFT_N - 1) % FFT_N` / `(id.x + 1) % FFT_N`（y 同理）。

**实测**：竖缝尖峰 **4.91@450 → 2.00@438**（2.0 是纯噪声水平，缝消失）。✅

## 7 人话版

- **白点**：一开始以为是"亮闪"造成的，改完发现**一个像素都没变**。于是一个个关掉试——关掉"碎闪"白点立刻少 73%，才找到真凶：碎闪的锐度设成了 420，等于"只有法线正对太阳的像素才亮"，远处就是随机撒盐。改成"近处锐、远处柔"，白点少了 **64%**，亮度对比几乎没动。
- **沙洲花纹**：修是修了，但修在了另一个 shader 上——Islet 的沙洲是地形贴图，不是沙滩 shader。这轮没解决。
- **FFT 竖缝**：真因很干脆——求梯度时在贴图边缘"不环绕"，把步长砍了一半，于是每条边界的法线断一次。改成环绕后，竖缝指标从 4.91 掉到 2.00，**缝没了**。
- **礁石珊瑚**：岛上原来一个碰撞体都没有，射线打点全落空；换用地形高程就放上了 26 块石头 + 14 丛珊瑚。但长得不好看——石头是黑点，珊瑚是彩点。
- 另外还发现：白点消失以后，泻湖里**露出一条竖着的接缝**，原来一直被白点盖着。
