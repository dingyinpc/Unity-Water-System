# R34 倒影镜面完整性轮 —— Main 平面镜像兜底

> 2026-10-25 深夜。R33 盲看点名的"最大剩余缺口"：倒影亮度/镜面完整性（SSR 结构级）。
> 解法：把潭（Pond）已有的**平面镜像反射**整套移植到 Main——同一个组件、零新系统。

## 人话版小结

屏幕空间反射有个天生短板：**只能映"画面里已经有的东西"**——树一旦有一半在画面外，倒影就缺一半；所以之前水塘的倒影总是一块一块碎的，加密步数（R33）只是缓解。
潭里早就有一条"真镜子"方案：在水面下藏一台**对称的相机**，把整个岸上世界照镜子拍下来给水面用。这轮把这台"镜子相机"也装到了主线水塘：SSR 照得到的地方仍用 SSR（最准），照不到的地方用镜子画面（保证完整连续）。
结果：盲看倒影从"碎块"变"**连续完整、能认出树/岸/天空、无穿帮**"，7/10。代价是每帧多花约 2.5 毫秒（帧耗 6.4→8.9ms，仍有 112fps 上界）。

## 实现

| 件 | 内容 |
| --- | --- |
| shader | `Water_Advanced` 反射兜底链从两层（天空↔SSR）升三层：**天空 ↔ 平面镜像 ↔ SSR**。SSR 命中（conf 软化）优先，miss 处 lerp 到 `_PlanarRef`（镜像相机 RT，波纹扰动与潭同款），镜像相机背后再退天空。`_PlanarStrength` 默认 0 ⇒ 不装相机**逐位零回归** |
| 组件 | 直接复用 `PondPlanarReflection`（全场景通用：镜像位姿 + 斜投影裁剪 + 每帧写材质矩阵/纹理）。Main 的 Water GO 挪到 layer 4（镜像相机按这层自剔，潭同款手法；Main 交互不走物理射线，改层无副作用） |
| 菜单 | `Tools/R34/90 装`（建 MainPlanarCam + 按材质锚点找水 + _PlanarStrength=0.85）/ `90b 拆` / `99 探针` |

## 证据

- **盲看**（`r34_main.png`，S3 参考 f650/f870）：倒影"连续完整、可认出树/岸/天空、无错位颠倒重复"→ **7/10**（扣分在清晰度/亮度仍有空间）。
- **静态**：37.8% 像素变化、std 75.1→77.3（倒影有了结构对比度）、全图亮度 122.0→122.2 守恒。
- **D 判据**（vs S3 f600-990，颗粒关）：water E ρ0.546→**0.55 稳定入带**；sky E 0.722→0.751 微升；spk 7.23→7.38 同族（泵拍频抖动旧账）。**平面镜像零判据回归**。
- **性能**：582 实测 Main avg 8.9ms（R22 基线 6.4ms；+2.5ms = 0.5× 分辨率镜像相机一次场景渲染，阴影/后处理已关）。嫌贵可把 `resolutionScale` 降到 0.4。

## 踩坑记档

- **退 Play 再切场景**：Pond 回归采集后忘了退 Play，120 切 Main 静默失败，A/B 两张拍到同一张 PondScene 旧帧（统计逐位相同=拿来当"没变化"的证据就是假证）。之后 125 探针先验场景再拍。
- **按材质锚点找水**：GO 名字随菜单版本变过（"Water"/"PoolWater"/…），`shader.name.Contains("Water_Advanced")` 才是稳定锚点。

## 遗留

- 倒影清晰度/亮度仍差参考一档（镜子 0.5× 分辨率 + 波纹扰动的柔化）——可调 `_PlanarDistort` 收紧或提分辨率。
- R31 清单剩余：Islet 远景岛（等岩型线收口）、FFT 云天空、昼夜分时专项（S11）。
