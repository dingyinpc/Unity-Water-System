## 2. M1 门禁：δ谱单元自检（先证计算正确再谈画面）

**结果 PASS**：λ=31.3m 单色波，相速度实测 **7.254 m/s vs 理论 √(g/k)=6.985（误差 3.9%<10%）**；
幅值实测 0.00024 vs 解析 0.00024（**误差 0.0%**）；δ 幅值 64→8 读数线性缩放 ✓。

自检抓出并修掉的四个真 bug（都是"画面看不出、量具现形"型）：
1. **FFT twiddle 符号被负号吃掉**——`tw=(c,−s)` 恒前向变换，正逆不分；δ 谱（恒模）测不出，
   离线对 numpy 复算实锤（修正后误差 1e-15）；
2. **镜像纹素公式**——`(id+N/2)%N` 是 fftshift 象限交换不是 −k，正确为 `(N−id)%N`；
3. **δ谱构造**——两 bin 都设实数 = 驻波（H 恒实、空间相位不动），行波需单边频率构造；
4. **读回双重校正**——Pack 已做棋盘频移，读回再乘一次 = 把行波读成奈奎斯特斑马纹。

排障铁证：把 δ 幅值 64→8 输出逐位不变 → 判定谱没进管线 → 定位到 **CPU Texture2D 绑 RW 槽
（UAV）静默失败**，改为 GPU 端 InitDelta 内核直写。
