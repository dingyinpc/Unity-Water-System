### 1.4 结论

参考在 S9 用的是**一整片海的全场浅水水流模拟**，含四个可辨识组件：
① 交错网格（MAC）水位/速度场；② 干湿边界判定（水随水位进退）；
③ 水位梯度驱动 + 摩擦 + 边界吸收；④ 岸线距离场把外海浪推进近岸。

## 3 差距对比

| 口径 | 参考 (66–78s) | 我方 (验收图) | 差距 |
| --- | --- | --- | --- |
| 水面 RGB | (34,121,170) | (92,121,140) | 我方 **R 高 2.7 倍**、B 低 → 灰而不饱和 |
| 近岸活动区 | 白沫 4.64% / 运动 3.46 | 细白线 / 无水流 | **无速度场 ⇒ 无"流"** |
| 干湿边界 | 有（随水位进退） | 无 | 完全缺 |
| 边界吸收 | 有（防反弹） | 无 | — |
| 外海浪驱动近岸 | 有（岸线距离场） | 无 | — |

**定性差距（逐条）**：
1. ❌ 无**水流速度场**——这是根本差异，其余四项都挂在它上面。
2. ❌ 无**干湿判定**：水线不是"水随水位进退"算出来的，是几何切割。
3. ❌ 无**水位梯度驱动**：水没有"往低处流"的动力学。
4. ❌ 无**摩擦/边界吸收**：即使加了速度场也会出现边界反弹。
5. ❌ 无**岸线距离场驱动的外海浪推进**：近岸水不会因外海涌浪而涌动。
6. ⚠️ 水色偏灰、饱和不足（次要，属调参层，但近岸"流动感"缺失会放大观感差距）。

## 4 补齐实施（方案设计）

### 4.1 技术方案（照参考 C14–C17 的完整链路）

**MAC 交错网格浅水方程**（逻辑层 ping-pong RT，`Graphics.Blit` 全平台稳）：

| RT | 分量 | 内容 |
| --- | --- | --- |
| `_SW_Terrain` | R | 地形高度（来自 `OceanShore.hlsl` 的 `SandY` 剖面） |
| `_SW_State` | R,G,B,A | 局部水深 h / 湿干标记 / 备用 / 备用 |
| `_SW_VelX` | R | X 格面速度 u（交错：位于 x 单元边） |
| `_SW_VelZ` | R | Z 格面速度 v（交错：位于 z 单元边） |
| `_SW_Foam` | R | 泡沫历史密度（供 P1-2 复用） |

**每帧步进**（blit 三步或一个多 pass shader）：
1. **干湿判定**：`wet = (terrain + h) > terrain`（比较当前水面高度与地形水底高度）；
2. **水位梯度→速度**：`Δu = -g · ∂(terrain+h)/∂x · dt`，`Δv = -g · ∂(terrain+h)/∂z · dt`（C15）；
3. **曼宁摩擦 + 指数衰减**：`u *= manningFactor · exp(-k·dt)`，限幅（C16）；
4. **边界吸收带**：`smoothstep(0, band, distToBorder)` 权重 × 指数衰减，同步降 h 与 v（C16）；
5. **外海浪驱动**：用岸线距离场算离岸距离与朝岸方向，`h += fftHeight · shoreWeight`，沿朝岸方向加 u/v 扰动（C17）。

## 6 遗留与风险

1. **性能风险**：4~5 张 RT 逐帧 blit + 水面额外采样；需按 §5-6 实测，必要时降分辨率/降更新频率。
2. **尺度风险**：`OceanScene` 岸线带多宽、网格覆盖多少，需先看场景实际（本次未打开 Unity）。
3. **与 S10 泡沫的接口**：本步产出的 `_SW_Foam` 历史密度正是 P1-2 的输入，建议 P0-1 就把泡沫写入通道留出来，避免二次改 RT 布局。
4. **水色**（R 通道偏高）属调参层，建议并入本步末尾一次调（不要单独开步），且遵《06》第 9 级"曝光→光源→反照率→色相"顺序。
