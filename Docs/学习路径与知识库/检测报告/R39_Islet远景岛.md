# R39 Islet 远景岛剪影（R31 Islet#4 收口）

参考定标（f0062/f0166）：地平线右侧一座低矮深蓝灰剪影岛、贴线、占宽 3-4%。
实现：程序化低模脊线山丘（14 段椭圆底+起伏脊+底裙）+ Unlit 深蓝灰材质，主岛在 207 片头机位右远方（-2700,0,1400）、次岛更远更小做纵深。全部加法（R39/90 装、90b 拆）——岩型线若合并场景，"对方优先+重跑菜单"即恢复。

判据：像素检出右带 117px 剪影（占宽 6%，带内）；视觉 **8/10**"贴地平线、轮廓模糊、与雾融合良好、位置与参考一致"。
