# R43 Main 瀑布悬崖（R41 B1：参考标志性元素）

程序化全加法：3 块低模岩壁 + 外弓瀑布带（双层滚动条纹白青双色）+ 落水泡沫盘（径向翻滚）。`WaterFall.shader` 双模式（带/盘）。菜单 R43/90 装、90b 拆。

**迭代记录**（两个真教训）：v1 窄版 6/10"可见无穿帮但比参考窄"→ v2 加宽后**全画面黑屏**(mean 29.7)：以为是大岩投影，关投影无效(43)，拆瀑布隔离实锤=**遮挡**——放错了塘端（相机在 -z 朝 +z，崖放 -z 糊镜头）；v4 搬到 +11 远端 → mean 94.5 正常，**盲判 7/10**"位置正确、亮度正常、气势略逊参考"。

**回归**：瀑布岩压水带能量，water E ρ0.55→0.468 掉带；浅水提亮一档(0.30,0.62,0.68)后 **0.499 带沿**（差 0.001，再压过曝，记档）。full E 0.548 PASS；spk 泵频旧账族。
**遗留**：气势再上一档要崖顶加宽+水雾粒子（下一轮）；Main 亮度已两档到顶。
