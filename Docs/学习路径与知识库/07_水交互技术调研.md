# 《07》水交互技术调研 —— 泳池线（PoolScene）的技术选型

> 用户需求（2026-10-04）："我又看到了别人的水可以交互，我想要这样的效果，单独开个泳池场景，并去调研一下水交互用到的技术以及论文还有文档。"
>
> 本文档回答三件事：①"别人家的水"到底是什么技术；②每档技术的论文/文档出处；
> ③我们这条线选哪一档、为什么、怎么落地（结论先行：**B 档离散波动方程 + ping-pong RT**）。

---

## 0. 现状盘点：主线已有的交互是什么档

`Assets/Scripts/Logic/WaterInteractionManager.cs` + `WaterInteractionBlit.shader` +
`Water_Advanced.shader` 的 [5][7] 两路，实现的是：

- 交互事件（世界坐标+时间）每帧 Blit 进一张 256² ARGB32 RT；
- 每个**单独**画成一圈解析的扩张正弦环（贴花），带寿命淡出；
- `_RippleSources` 再叠 8 个程序化径向环。

**特征：无状态、无传播。** 涟漪不会从 A 点传到 B 点、不会从池壁反弹、
两圈涟漪相遇不会干涉——它画的是"事件的印章"，不是"波动的场"。
作演示点缀够用；作"别人家那种水"（扔一块石头，波纹荡开、撞壁反回来）差一个数量级。

## 1. 技术谱系：五档，按"物理正确度 × 实现成本"排

| 档 | 技术 | 传播/反射/干涉 | 成本 | 代表用途 |
|----|------|----------------|------|----------|
| A | 解析贴花（主线现状） | ✗ | 极低 | 点缀、雨圈 |
| **B** | **离散波动方程高度场（ping-pong RT）** | **✓/✓/✓** | **低（两张 RT + 一个 blit）** | **泳池、浅水交互、雨面** |
| C | 波粒子 Wave Particles（拉格朗日） | ✓/✓/✓ + 色散可选 | 中（粒子系统 + 投影） | 船尾迹、Open Sea（神秘海域3） |
| D | 水面小波 Wavelets（空间-频率-方向幅值场） | ✓/✓/✓ + 色散 | 中高 | 大型交互水面 |
| E | 粒子流体（SPH / PBF） | 真 3D 流体 | 高 | 飞溅特写、小容器 |

补充一个不进榜的：**FFT 谱海洋（Tessendorf）**——离线生成 displacement 贴图循环播，
好看但**不可交互**（没有"往里扔东西"的输入口），主线/开海线的思路即源于此。

### 各档细节与出处

**B 档：离散波动方程（本线选型）**
把水面当作 2D 波动方程 `∂²h/∂t² = c²∇²h` 的离散解，高度场存两张 RT 交替读写
（"上一帧"和"这一帧"），每帧一次 blit：

```
next(x,y) = ( curr(x±1,y) + curr(x,y±1) ) × 0.5 − prev(x,y)     // 离散波动方程
next *= damping                                              // ~0.996，能量衰减
```

这就是流传最广的 **Hugo Elias 两缓冲波纹算法**。要点：

- **传播速度**由网格比决定（c = 0.5/√2 格/步 @ 上面这式），想更快每帧跑 2 次 blit；
- **边界**：采样 `Clamp` 就是**刚壁反射**（Neumann 边界）——对泳池来说这是白送的：
  涟漪传到池边自动反弹回来，正好是"别人家的水"的核心观感；
- **注波**：交互帧在写入时叠一颗高斯脉冲（一次性冲量，不是持续外力）；
- **渲染端**：对高度场求梯度得法线（`n = normalize(-∂h/∂x, 1, -∂h/∂z)`），
  顶点位移可选（泳池浅、幅度厘米级，法线为主位移为辅）。
- 参考实现：jeantimex/webgpu-water（WebGPU，双缓冲 + 每帧两步保稳定）；
  Unity 侧老帖（Hugo Elias GPU ripple）；本项目落地的 `PoolWaveUpdate.shader`。

**C 档：波粒子（Wave Particles）**
Yüksel, House, Keyser, *"Wave Particles"*, ACM SIGGRAPH 2007。
波的能量由**粒子**携带（拉格朗日），每个粒子是一圈扩散的圆环波，
遇障碍物反射/衍射时粒子被劈成子粒子。无条件稳定、不需要网格，
**船尾迹和物体拖尾是它独门的强项**。后续 Naughty Dog 把它用在《神秘海域3》
做局部高频水面。实现复杂度中高（粒子管理 + 环投影到高度图）。
衍生物：Jeschke et al., *"Water Wave Packets"*, SIGGRAPH Asia 2017（加色散）。

**D 档：水面小波（Water Surface Wavelets）**
Jeschke, Skalla, Mitchell, …

（参见 ACM TOG 37(4), SIGGRAPH 2018。把波场离散成"空间×频率×方向"的幅值函数，
传播是局部平移——比波粒子省、比波动方程多色散和方向性。Crest Ocean System
把它列为设计灵感。目前没有量大管饱的 Unity 参考实现，先记录不选。）

**E 档：粒子流体**
Macklin & Müller, *"Position Based Fluids"*, ACM TOG 32(4), SIGGRAPH 2013（PBF）；
Müller et al., *"Particle-based Fluid Simulation for Interactive Applications"*, SCA 2003（SPH）。
真三维流体，能做飞溅、浇水、容器倾倒；几万粒子起步，泳池整面用它属于杀鸡用牛刀。
**飞溅特写**可以后续用 PBF 的"局部小坨"补。

**交互物浮力（扔球沉浮）**：游戏界标准做法是 Jacques Kerner 的两篇
*Water interaction model for boats in video games*（Part 1 排水体积采样浮力 +
Part 2 水面对船的反作用），不需要流体求解器——把物体切片采样浸没体积即可。
这是下一阶段"往泳池里扔球"的算法基础，本轮不实现。

### 泳池特有的渲染件（与交互正交但同属"别人家的水"）

- **焦散（caustics）**：光经波面折射在池底聚成的亮网。
  全解 = 折射光线锥交底面（贵）；业界常用 = **程序化焦散动画纹理**
  （两层变形噪声/相位网格取 max/abs，随时间流动，durablescope 的实现最清晰）；
  进阶 = **用波动方程的高度场梯度直接调制焦散强度**——波峰聚光波谷散光，
  一行乘法就能让焦散"跟着涟漪动"，本项目采纳。
- **清水折射**：泳池水深 1.3m、吸收系数要小，池底瓷砖要"看得清但隔层水"。
- **瓷砖底/壁**：程序化瓷砖（0.2m 格 + 灰缝 + 哈希明度扰动），不引美术资产。

## 2. 选型结论与理由

**泳池线选 B 档（离散波动方程），理由：**

1. **观感对位**：用户指的"别人家的水"（可传播、撞壁反射、互相干涉）正是 B 档的
   全部特征；C/D 档的优势（色散、方向性）在 1.3m 深的小水池里几乎不可感知——
   深水波色散在厘米-分米波长上效应微弱。
2. **成本**：两张 RHalf RT（256²）+ 每帧 1~2 次 blit，比主线的贴花还便宜；
   不用 compute shader（Graphics.Blit 全平台稳，且和主线交互系统的
   "Update 里 blit"先例完全同构，工具链（探针/桥）零新增）。
3. **风险**：B 档是五种里参数最少、最不会爆炸的（无条件稳定），调参只剩
   阻尼 × 速度 × 注波强度三个数。
4. **升级路径清晰**：B 的接口（高度场 RT）就是 C 档波粒子的输出格式
   （波粒子最终也投影成高度场），将来船尾迹可以"喂进同一张图"，渲染端零改动。

**明确不做**（本轮）：粒子流体、色散、船体浮力——记录在案，见《06》之后的路径。

## 3. 泳池线（PoolScene）落地设计

- **场景**：`Assets/Scenes/PoolScene.unity`，第 5 条水线，前缀 `Pool*`（与
  Pond*/Ocean*/Islet* 的前缀纪律一致，互不碰撞）。
- **几何**：池体 12m×6m，水深 1.35m（池底 y=−1.35），水面 y=0，四周压沿台 +0.12m；
  瓷砖底/壁（程序化），水面网格 96×48（顶点位移用）。
- **模拟域**：高度场 RT 精确覆盖 12×6m（256² → 4.7cm/格），Clamp 采样 = 池壁反射。
- **交互输入**：鼠标左键点水面注一颗高斯脉冲（相机射线与 y=0 平面求交）；
  空格 = 自动演示滴落；`PoolRipples` 组件持有双缓冲并每帧步进。
- **渲染**：`Water_Pool.shader`——波场法线（主）+ 顶点位移（辅）+ 屏幕空间折射
  （搬瓷砖底）+ 程序化焦散（波场梯度调制）+ 菲涅尔天空反射（克制）+ 太阳高光。
  水深用**解析常数**（池底平），不再碰深度纹理（《07》前车之鉴）。
- **取帧**：复用 `GameViewCapture`（95b 通路）；深度无关判据不依赖深度纹理。

## 5. 验收判据（本线的"量具"）

1. **传播**：点 A 注波，0.5s 后距 A 2m 的 B 点出现可见起伏（传播速度 ~4m/s @ 每帧 2 步）。
2. **反射**：涟漪到池壁后折返，与入射波干涉出菱形纹。
3. **衰减**：无新输入时 4~6s 内水面回到镜面（damping ≈ 0.996/步）。
4. **渲染**：波峰处焦散增强、波谷处减弱（梯度调制生效）；瓷砖经折射可见但发"水色"。
5. **性能**：Play 模式 ≥ 300 FPS（探针 FRAME ms 例行打印）。
