# 学习路径与技术栈（02）

> 出发点：2D Unity 开发较精通、3D 陌生但基础扎实。
> 目标：通过复刻《unity 水体 shader》视频，系统补齐 3D 水体渲染所需技能，并能独立复现。
> **动手主线在《06_从零写一个水体材质》**（空文件 → 9 级 → 成品水面）；本文的"分技术路径"是为它补地基，理论细节在《01》。

## 一、从 2D 到 3D：需要补的三块地基

| 能力 | 2D 状态 | 3D 水体需要 | 本项目里的落点 |
| ---- | ------- | ----------- | -------------- |
| 空间数学 | 常用 xy 轴（UI/2D 世界） | 三维向量、点积/叉积、矩阵变换（模型/视/投影）、齐次坐标 | §1 格斯特纳、§6 法线混合、§3 屏幕 UV |
| Shader 认知 | 2D 精灵/UI 通常走内置 or 简单 shader | 自定义 HLSL：顶点/片元/细分阶段、向量运算、采样 | 整个 Water_Advanced.shader |
| 渲染管线 | 2D 常用默认/URP 2D | URP 3D：透明队列、Opaque Texture、深度纹理 | §3 §4 折射与深度保护 |

> 语言与版本：HLSL 语法 + Unity `Shader "..."{}` 结构；本项目用 **URP 14 + 2022.3.57f1c2**（LTS）。

## 二、分技术学习路径（每项：学什么 → 做到什么 → 验收）

### 1. 向量与坐标（半天）
- 学：加/减/点积/叉积/归一化；模型、世界、视口、屏幕坐标转换；MVP 矩阵含义。
- 验收：能手算"一个点在相机空间投影到屏幕 UV"。
- 资源：3Blue1Brown 线性代数系列；Unity Manual (Transform/Space)。

### 2. Shader 入门（1~2 天）
- 学：ShaderLab 结构、Properties/CGPROGRAM、顶点与片元着色器分工、`_Time` `_WorldSpaceCameraPos` 等内置变量；`sv_position`/`TEXCOORD` 语义。
- 验收：写一个"随时间起伏的平面"顶点位移 shader。
- 资源：Unity 手册（SL 系列）、Catlike Coding（Rendering 系列）、Leaves 的 Unity Shader 入门。

### 3. 格斯特纳波（1 天）
- 学：§1 公式推导（位移/法线/陡度 Q）；多波叠加。
- 验收：平面上四条波叠加，法线光照正确（无断裂、法线 renormalize）。
- 资源：GPU Gems 1 Ch.1（本仓库《01_水体渲染知识库》§1）。

### 4. 曲面细分（1 天）
- 学：DX11 管线 Hull→Tessellator→Domain；细分因子语义（SV_TessFactor/SV_InsideTessFactor）；距离/屏幕误差判据。
- 验收：近处细分可见、远处平滑；性能帧率可接受。
- 资源：Unity 手册曲面细分页、微软 DX11 Tessellation 文档。

### 5. 折射 + 深度保护（1 天）
- 学：Opaque Texture 原理；深度纹理采样；线型深度换算；菲涅尔。
- 验收：水底石头被正确"掰弯"，近岸/掠射不穿帮。
- 资源：URP 文档（深度与不透明纹理）、GPU Gems 折射章节（选读）。

### 6. 交互 + 程序 ripple（1~2 天）
- 学：RenderTexture 写入/采样、正交投影矩阵；径向正弦 ripple 公式。
- 验收：点击/物体落水产生涟漪与溅起泡沫，并随距离衰减。
- 资源：《01_水体渲染知识库》§5 §7。

### 7. RNW 法线混合 + 浪尖（1 天）
- 学：解析法线与细节法线按距离加权；压缩度 J 判据（§8）；泡沫三源混合。
- 验收：浪尖白沫只出现在卷曲处，泡沫随波运动，远近过渡无缝。
- 资源：《01_水体渲染知识库》§6 §8。

### 8.（延伸，可选）FFT 海洋
- 学：Tessendorf 频谱法、IFFT、Johanson 论文；时间预算充足再碰。
- 本项目不做，仅知识储备。

## 四、时间与精力建议

- 每天 2~3 小时连续投入，预计 **1.5~2 周** 完成全部 8 项技术（含踩坑）。
- 卡住时的原则：先查《05_踩坑全记录》（按类别整理，绝大多数坑已经踩过并记了根因）→ 再看《01_水体渲染知识库》理论 → GPU Gems 原文 → 最后全网搜报错片段。每解决一个新坑，回填到 `05_踩坑全记录.md` 对应类别，并在 `03_可复现流程.md` 留一条时间线记录。
